# Tic-Tac-Toe – Arcade Edition

Jeu de morpion développé en Python avec CustomTkinter, proposant une interface graphique personnalisée et deux modes de jeu : joueur contre joueur et joueur contre IA.

## Mon travail sur le projet

Je me suis principalement concentré sur le développement du backend et de l'intelligence artificielle, tout en participant à la conception de l'interface graphique.

- **Backend :** développement de la logique du jeu, gestion des tours, validation des coups et détection des fins de partie.
- **Intelligence artificielle :** développement d'une IA capable de rechercher les coups gagnants, de bloquer l'adversaire et de choisir ses actions.
- **Interface graphique :** conception du design, intégration des fonctionnalités et gestion des interactions avec CustomTkinter.

## Fonctionnalités

- Mode 2 joueurs.
- Mode contre l'intelligence artificielle.
- Système de scores.
- Détection automatique des victoires et matchs nuls.
- Relance et réinitialisation des parties.
- Interface graphique personnalisée avec thème sombre.

## Technologies utilisées

- Python
- CustomTkinter

## Installation et lancement

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/RayaneBouzakiDev/tic-tac-toe-python.git
   ```

2. Accéder au dossier :

   ```bash
   cd tic-tac-toe-python
   ```

3. Installer les dépendances :

   ```bash
   pip install customtkinter
   ```

4. Lancer le jeu :

   ```bash
   python main.py
   ```
